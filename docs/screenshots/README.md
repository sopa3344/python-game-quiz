# 제출용 원본 화면 캡처

현재 폴더에는 실제 터미널 스크린샷이 없습니다. `../evidence/`의 텍스트는 실제 프로그램 출력이며 이미지로 꾸며 터미널 원본이라고 표시하지 않았습니다.

| 파일명 | 실제 실행 후 찍을 화면 |
| --- | --- |
| environment.png | VS Code 프로젝트, python --version, git --version과 작성자 설정 |
| menu.png | python main.py로 실행한 메뉴 |
| add_quiz.png | 문제와 네 선택지를 입력하고 저장 완료 |
| list.png | 새로 등록한 문제를 포함한 목록 |
| play.png | 마지막 문제와 게임 결과 |
| score.png | 종료 후 재실행한 최고 점수 |
| git-log.png | git log --oneline --graph --all 출력 |

계정 비밀번호나 토큰이 보이는 화면은 캡처하지 않습니다. 기록 예시는 학습 보조 도구가 실행한 내용이며 사용자 본인의 수행 화면과 구분합니다.
